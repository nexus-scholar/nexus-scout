# Phase 4: Validation Gate & Handoff (`ValidationScreen.tsx`)

## Overview
The agent loop has finished successfully. This screen allows the human researcher to review the AI-generated protocol parameters, inspect the raw `nexus.yml` configuration file, and finally authorize the system to trigger the `nexus-research` Python CLI for extraction.

## UI/UX Blueprint
- **Layout**: Clean Document/Review Dashboard.
- **Header**: "Protocol Successfully Generated" with success metrics (e.g., "Golden Seeds Found: 4/5").
- **Main View (Split)**:
  - **Tab 1 (Structured View)**: A human-readable breakdown of the Boolean strings, the target journals, the inclusion/exclusion criteria, and the date ranges.
  - **Tab 2 (Code View)**: A syntax-highlighted code block displaying the raw `nexus.yml` payload generated by the backend.
- **Action Buttons**:
  - `Edit Protocol`: Sends user back to Interview phase or allows manual override.
  - `Approve & Run Nexus`: The final CTA that executes the actual data scrape.

## State & Frontend Logic
- **React Management**: Fetch the finalized thread data via standard REST API on load.
- **Code Highlighting**: Use a lightweight library like `prismjs` or `react-syntax-highlighter` to format the YAML file beautifully.
- **Final Submission**: Triggering "Approve" fires a terminal request to the Laravel backend.

## Laravel Backend Contract
- **Endpoint 1 (Fetch Protocol)**: `GET /api/v1/threads/{thread_id}/protocol`
  - **Response**: Returns the fully assembled `AgentState` including `golden_seeds_found`, `boolean_strings`, and the literal `nexus_yaml` string buffer.
- **Endpoint 2 (Run Nexus)**: `POST /api/v1/threads/{thread_id}/execute`
  - **Backend Action**: 
    1. Laravel creates a physical `/storage/app/nexus/thread_{id}.yml` file containing the payload.
    2. Laravel dispatches a `RunNexusPipeline` Job.
    3. Inside the Job: `Process::path('/path/to/nexus/')->run('python -m nexus cli search --config /storage/app/nexus/thread_{id}.yml');`
    4. Provide the user a generic "System is running extraction, you will be emailed when your CSV is ready" alert.
